VectraMail

A personal desktop email client for macOS · 个人自用的 macOS 邮件客户端

VectraMail is a native macOS email client used privately by its developer. It connects directly from the user's Mac to the user's own mail servers (for Gmail: imap.gmail.com and smtp.gmail.com) to read, organize and send email.

When a Gmail account is added, VectraMail uses "Sign in with Google" (OAuth 2.0) so that no Google password is ever stored. The access granted is used only to sync and send the signed-in user's own mail over IMAP/SMTP.

VectraMail 是开发者自用的 macOS 原生邮件客户端，直接从用户自己的电脑连接邮件服务器收发邮件。添加 Gmail 账户时使用 Google 登录授权，不保存 Google 密码；授权只用于收发该用户自己的邮件。
